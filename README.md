# GramCo - Sentence Structure & Teacher Score Portal

GramCo is an interactive educational web app designed to develop Grade 6 sentence structure skills with an educator portal for compiling student scores across multiple devices.

## Features
- **5 Interactive Learning Missions**:
  - Session 1: Completeness of Thought
  - Session 2: Word Order and Arrangement
  - Session 3: Subject-Verb Agreement
  - Session 4: Punctuation and Capitalization
  - Session 5: Putting It All Together
- **Pre-Test & Post-Test**: 20 diagnostic questions benchmarked against DepEd competencies.
- **Teacher Portal (PIN Protected)**:
  - Real-time Class Session Release controller syncing session gates across all student devices.
  - Multi-tab Excel (.xlsx) export.
  - Separated CSV Exports:
    - Dedicated Test Scores CSV (Pre-Test vs Post-Test comparison, net score gain, dates, and competency breakdown)
    - Dedicated Session Progress CSV (Sessions 1 to 5 status, completion timestamps, completion rates)
    - Item Analysis CSV (question difficulty index $p$, mastery %, and DepEd difficulty classifications)
    - Master Separated CSV with distinct partitioned sections.
